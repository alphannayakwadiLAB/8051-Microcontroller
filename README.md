# 8051 Microcontroller  A complete collection of my work with the 8051 microcontroller: notes, code, practical projects, and simulations, organized in one place for learning, reference, and portfolio use.  ## What's inside  - **Documents**: Notes and reference material covering 8051 architecture,   memory organization, registers, instruction set, timers/counters,   interrupts, and serial communication. - **Programs**: Example programs for core topics such as I/O port handling,   delays using timers, interrupts, LCD and keypad interfacing, and UART   communication. - **Projects**: Applied mini-projects built around the 8051, each in its own   folder with source code and a short explanation. - **Simulation Files**: Circuit and code simulation files (e.g. Proteus / Keil),   so each program and project can be tested without physical hardware.  ## Tools  - Keil µVision for writing and compiling code - Proteus for circuit simulation - Language: Embedded C / Assembly  ## Repository structure  8051-microcontroller/ ├── Documents/ ├── Programs/ ├── Projects/ ├── Simulation/ └── README.md  ## How to use  1. Clone the repository. 2. Open the program or project in Keil and build it to generate the HEX file. 3. Load the HEX file into the matching simulation file to see it run.  ## Author  Alphan, embedded systems design student
